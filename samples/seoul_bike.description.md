# Seoul Bike Sharing Demand — кандидат для презентації

Файл: seoul_bike.csv. Офіційне джерело: https://archive.ics.uci.edu/dataset/560/seoul+bike+sharing+demand ; DOI: https://doi.org/10.24432/C5F62R . Посилання для атрибуції: Seoul Bike Sharing Demand [Dataset]. (2020). UCI Machine Learning Repository. Ліцензія UCI — CC BY 4.0, потрібне зазначення джерела.

Одна одиниця спостереження — одна година роботи/стану міської системи прокату. Дані за 2017-12-01 — 2018-11-30; 8760 рядків, 14 стовпців. Ціль для демонстрації — Rented Bike Count, кількість прокатів за годину. Це реальні спостереження, не синтетичний набір.

| Поле CSV | Значення / одиниця |
| --- | --- |
| Date | Дата, фактичний формат дд/мм/рррр |
| Rented Bike Count | Кількість прокатів за годину; ціль |
| Hour | Година 0–23 |
| Temperature(°C) | Температура, °C |
| Humidity(%) | Відносна вологість, % |
| Wind speed (m/s) | Швидкість вітру, м/с |
| Visibility (10m) | Видимість в одиницях 10 м |
| Dew point temperature(°C) | Температура точки роси, °C |
| Solar Radiation (MJ/m2) | Сонячна радіація, МДж/м² |
| Rainfall(mm) | Опади, мм |
| Snowfall (cm) | Сніг, см |
| Seasons | Сезон: Winter, Spring, Summer, Autumn |
| Holiday | Holiday / No Holiday |
| Functioning Day | Yes / No: чи працювала система прокату |

У CSV лише змінено кодування оригіналу Latin-1 на UTF-8 для правильних символів °C; назви, рядки й значення не змінено. Оригінальний архів можна завантажити з UCI за посиланням вище. SHA-256 файлу для завантаження: d2f7a0f0ba95e82678ead794429a18a7f696aa3b82c9b9ec34ec47806ff0767b.

Наш read_table/profile підтвердив: UTF-8, кома, 604168 байтів; пропусків і повних дублікатів немає. 295 годин мають Functioning Day=No. Нульовий попит через закриту систему не змішувати з низьким попитом у відкритій; для моделі попиту пропонується явно відфільтрувати No із збереженням оригіналу.

Ці дані мають часову залежність. Наявний у MVP випадковий поділ демонструє зв’язки, але не є перевіркою прогнозу майбутнього. Hour краще трактувати категорією для різних годин; за непогодженого перетворення не видавати регресію з лінійною Hour за модель добового циклу. Температура і точка роси можуть дублювати інформацію. Лінійна регресія не гарантує невід’ємних прогнозів для кількостей. Числова якість моделі на цьому наборі ще не перевірена.
