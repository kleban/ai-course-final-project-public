# Демонстраційні дані

## Основний демонстраційний набір — Melbourne Housing Snapshot

`melb_data.csv` — продажі житла в Мельбурні (січень 2016 — вересень 2017), задача — лінійна регресія ціни `Price`. Джерело, ліцензія CC BY-NC-SA 4.0 та оригінальний опис полів — [`melb_data.description.md`](melb_data.description.md); цей файл також є сирим описом для кроку 02b.

Перевірено нашим `read_table` і `profile`: UTF-8 (BOM), роздільник `,`, 13 580 рядків × 21 стовпець, повних дублікатів немає. Пропуски: `BuildingArea` 6450, `YearBuilt` 5375, `CouncilArea` 1369, `Car` 62. Категоріальні: `Type` (h/u/t), `Method` (5), `Regionname` (8), `Suburb`, `SellerG`, `CouncilArea`. Дата продажу `Date` у форматі `д/мм/рррр` — **зараз профіль визначає її як текст**, а `Postcode` — як число; це відомі обмеження профілювання.

## Синтетичний набір для автотестів

`demo_apartments.csv` (UTF-8, роздільник `;`) — **синтетичний** набір: 150 «квартир», ціна в тис. грн залежить від площі, відстані до центру, року побудови й району, з шумом і кількома пропусками. Числа вигадані й не є ринковими даними. Згенеровано `tools/make_demo_data.py` (фіксований seed). Використовується автотестами й UI-смоуком.

## Набір для демонстрації — Seoul Bike Sharing Demand

samples/seoul_bike.csv — 8760 погодинних спостережень, 14 полів, 604168 байтів. Джерело, ліцензія (CC BY 4.0) й одиниці — [`seoul_bike.description.md`](seoul_bike.description.md). Оригінал збережено; для імпорту змінено лише кодування на UTF-8.
